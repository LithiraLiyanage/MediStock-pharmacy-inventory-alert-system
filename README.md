## 🚀 Overview

**MediStock** is a modern pharmacy inventory dashboard built with **Python, Streamlit, SQLite, pandas, and Plotly**. It helps pharmacy staff track medicine stock, batch numbers, expiry dates, low-stock alerts, expired medicines, near-expiry medicines, stock value analytics, and CSV exports.

> ⚠️ Medical Scope: This project is for pharmacy inventory management and educational portfolio use only. It does not provide diagnosis, treatment advice, dosage recommendations, or drug interaction advice.

## ✨ Features

- 💊 Medicine inventory management
- 🏷️ Batch number tracking
- 📦 Quantity and reorder-level tracking
- 🚨 Low-stock and out-of-stock alerts
- ⏳ Expired and near-expiry medicine alerts
- 📊 Dashboard metrics and Plotly charts
- 🔍 Search and filter inventory
- 🔄 Stock in / stock out / adjustment tracking
- 🧾 CSV export reports
- ✅ Strong form validations
- 🎨 Custom red medical SaaS UI
- 🧪 Demo seed data included

## ⚙️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
